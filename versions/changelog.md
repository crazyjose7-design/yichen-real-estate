# 版本紀錄

## Regulatory dataset v0.1.0 — 2026-11-27
- 建立 22 個縣市獨立 JSON 檔。
- 建立中央法規索引及獨立法規紀錄。
- 建立 5 個稅目參數檔。
- 建立 9 個獎勵制度檔。
- 建立 master manifest、verified-only loader、資料驗證器及單元測試。
- 將法規、縣市、稅目、獎勵及文件納入部署 ZIP。
- 狀態：開發中；非正式法規資料庫，未接管正式試算公式，未部署正式網站。

## Regulatory dataset v0.1.1 — 2026-11-27
- 新增都市更新及危老兩項中央容積獎勵子法紀錄，納入條文摘錄、申請順序、互斥及上限查核點。
- 建立臺北、新北、臺中、高雄4縣市地方官方法規來源索引；18縣市仍未建立來源索引，4縣市內容也仍待逐條/基地覆核。
- 校正現行《都市更新條例》容積獎勵條號為第65條，補入一般1.5倍、法定特別上限、地方0.2倍/0.4倍上限及不得併用情形的待覆核摘錄。
- 五個稅目資料檔新增中央法條稅率/級距初步參數，狀態全為 in_review，禁止自動套用。
- 新增容積獎勵安全引擎及5項回歸測試；引擎尚未接入正式土地坪效頁面。
- 正式稅務公式尚未由參數檔驅動，A4列印版面與正式公式回歸測試仍未驗收。
- 狀態：開發中；不代表正式法規資料庫完成，未部署正式網站。
