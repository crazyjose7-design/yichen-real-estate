# 22縣市地方法規與基地管制覆核矩陣

目前22縣市均已建立獨立資料檔，並有36筆地方法規入口/來源紀錄；但22縣市資料檔的status仍全部為unverified，官方參數陣列均為0。這代表已建立研究入口，不代表已完成地方自治法規、都市計畫書圖、基地分區或個案核准查證。

逐縣市追蹤的機器可讀矩陣位於regulations/city-review-matrix.json。

## 共通覆核工作
1. 取得縣市主管機關法規原文、修正沿革、施行日期及所有附件/附表。
2. 逐一查閱都市計畫主要計畫與細部計畫書圖，確認計畫區、分區、容積率、建蔽率、退縮、高度、道路及其他基地管制。
3. 以實際地址/地號查核土地使用分區及基地條件，不能以縣市通則代替個案。
4. 逐項確認都市更新、危老、容積移轉、TOD、開放空間、綠建築、智慧建築等獎勵的適用條件、上限、互斥/併計及過渡規定。
5. 取得個案主管機關核准文件及核准增加樓地板面積後，才能建立可套用參數。

## 特別待覆核
- 南投縣：已定位都市設計審議原則及容積移轉作業要點，仍須核對最新沿革、附表與基地適用。
- 宜蘭縣：已定位都市設計審議作業要點及縣府都市計畫目錄；最新修正沿革待縣府原始全文確認。
- 臺東縣：目前取得都市設計審議原則縣府函文副本，仍待縣府原始公告及現行版本。
- 苗栗縣：地方容積獎勵辦法曾有內政部函告第3條無效紀錄，必須逐條核對有效範圍及後續修法。

## 安全狀態
22縣市全部維持unverified，官方參數不自動套用。完成法規來源定位、逐條法律覆核、基地圖資套疊及個案核准驗證後，才能逐項提升狀態。
