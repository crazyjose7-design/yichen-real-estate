# Simpany 欄位結構對照與重製驗收基準

## 必須遵循的基本欄位

### 租金扣繳
1. 房東類型：個人／公司。
2. 每期租金金額。
3. 租金是否已含稅：已含稅／未含稅。
4. 基本結果：每期租金、扣繳稅額、補充保費、租扣二代總額、實際支付租金。
5. 進階設定：可新增房東、設定每位房東持分比例、設定國別／稅務居住者狀態；按持分拆分各房東扣繳與補充保費。

### 執行業務所得
1. 身分（居住者／非居住者）。
2. 申報類別（9A執行業務所得／9B稿費等）。
3. 健保身分（用於判斷補充保費適用）。
4. 金額。
5. 公司端結果：所得金額、代扣所得稅、代扣補充保費、實際支付金額。
6. 個人端結果：所得金額、費用率、計入個人綜合所得的淨額。

## 禁止事項
- 不得將全年必要費用明細設為基本流程必填。
- 不得把健保身分藏成「使用者自行確認免扣」的單一勾選；必須提供清楚選項。
- 不得把房東國籍與稅法居住者身分混為同一概念；介面需用「國籍／居住者判斷」提示，實際計算依稅法居住者身分。
- 不得將租金未含稅視為單純租金原額；必須執行扣繳與補充保費的反推總額計算。
- 9A費用率必須依所得年度與職業別官方標準，不得猜測或沿用其他年度。

## 已知上一版不符合項目
- 租金基本欄位錯置，缺少含稅／未含稅切換、多房東持分。
- 租金公司房東與個人房東未正確分流。
- 執行業務所得缺少明確健保身分選項與9A/9B分類結果表。
- 將全年收入與費用明細過度放大為主流程，偏離參考工具的簡單操作。
