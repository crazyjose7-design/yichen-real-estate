# 億辰房產網站｜功能隔離與回歸防護規範

本文件是所有後續網站修改的強制工程規範。任何新增、修改、刪除、排版或修復工作都必須遵守。

## 1. 修改範圍隔離
- 每次工作先確認目標功能的 HTML 區塊、專屬 CSS、JavaScript 與 API，不得因方便而整頁重寫。
- 新增樣式必須使用該功能的根節點 ID 或唯一元件類別作為作用範圍；禁止以全站通用標籤選擇器改動其他功能。
- 新增腳本應限制在功能根節點內，避免污染全域變數、事件或其他元件狀態。
- 不得刪除或覆蓋未列入本次修改範圍的程式碼、資料、連結、計算規則及使用者已驗收設定。
- 共用元件要修改時，必須先列出所有依賴它的功能，並逐項回歸測試。

## 2. 已驗收功能保護
以下項目視為受保護功能；除非任務明確要求，否則不得改變其既有行為：
- 首頁品牌文字、主視覺、字型及響應式排版
- TikTok／YouTube 影片標題、縮圖、播放器及播放互動
- 房產資源專區及四個錨點導覽
- 稅務試算器與土地坪效試算器
- 縣市選擇器及既有輸入、計算流程
- 導覽列、手機版選單、列印版面及頁面版本資訊

## 3. 每次提交前的必要檢查
1. 比對本次變更與上一個已驗收版本，只允許預期檔案與預期區塊變動。
2. 執行 `node scripts/check-regression-contracts.mjs`。
3. 確認 GitHub Actions 的 Site regression contracts 通過。
4. 部署 Cloudflare Preview，不得直接推送正式 `main`。
5. 在桌面與手機尺寸檢查本次功能及受保護功能；影片需檢查標題、縮圖、播放，文字需檢查繁體中文與編碼，版本資訊需檢查窄螢幕顯示。
6. 發現任何回歸問題，停止擴大修改，先修復並重新部署、重新驗收。

## 4. 完成定義
- 程式碼檢查通過不等於瀏覽器驗收通過。
- Cloudflare 顯示 Preview 部署成功不等於功能已完成驗收。
- 只有程式檢查、Preview 部署及實際畫面測試都通過，才可標示為完成。
- 正式站 `main` 只有在另行明確授權後才可更新。
