# 中央法規、22 縣市與獎勵資料管理制度

## 資料拆分
1. `regulations/cities/`：22 縣市各自一檔。
2. `regulations/national/`：中央法律索引與獨立法規紀錄。
3. `regulations/rewards/`：容積獎勵/開發獎勵按制度獨立建檔。
4. `regulations/taxes/`：各稅目參數，與法規原文分開。
5. `regulations/schemas/`：資料格式約束。

## 驗證流程
收集官方法源 → 核對現行條文及施行日期 → 確認適用對象與管轄 → 建立參數 → 第二人覆核 → 公式/回歸測試 → 版本發布。任何一步未完成，狀態不得標為 verified。

## 獎勵資料特別規則
容積獎勵不可只存百分比。必須同時存法源、基準容積、計算方式、上限、資格、證明文件、審議/核准狀態、互斥與併計規則、有效期間。中央與地方規則分層；基地個案核准值須另存個案紀錄，不得污染通用法規參數。

## 本次建置狀態
已建立 22 個縣市獨立資料檔、中央法規索引檔及獎勵制度檔案骨架。內容目前全部標示 unverified；這是安全的資料架構起點，不等於完成法規逐條查證，也未接入正式試算引擎。

## 稅目參數獨立維護
地價稅、土地增值稅、房地合一所得稅、契稅及房屋稅各自獨立資料檔；中央法規只提供法源，不直接取代稅目參數與公式。各稅目資料未經查證前維持 unverified、空參數及禁止自動套用。
