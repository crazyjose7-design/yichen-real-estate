# 中央法規、22 縣市與獎勵資料管理制度

## 資料拆分
1. `regulations/cities/`：22 縣市各自一檔。
2. `regulations/national/`：中央法律索引與獨立法規紀錄。
3. `regulations/rewards/`：容積獎勵/開發獎勵按制度獨立建檔。
4. `regulations/taxes/`：各稅目參數，與法規原文分開。
5. `regulations/schemas/`：資料格式約束。

## 驗證流程
收集官方法源 → 核對現行條文及施行日期 → 確認適用對象與管轄 → 建立參數 → 第二人覆核 → 公式/回歸測試 → 版本發布。任何一步未完成，狀態不得標為 verified。

## 獎勵資料特別規則
容積獎勵不可只存百分比。必須同時存法源、基準容積、計算方式、上限、資格、證明文件、審議/核准狀態、互斥與併計規則、有效期間。中央與地方規則分層；基地個案核准值須另存個案紀錄，不得污染通用法規參數。

## 本次建置狀態
已建立 22 個縣市獨立資料檔、中央法規索引檔及獎勵制度檔案骨架。目前僅臺北、新北、桃園、臺中、臺南、高雄、基隆、嘉義市、苗栗、雲林、花蓮、澎湖 18/22 縣市建立官方地方法規來源索引，條文、附表、都市計畫書圖與基地個案仍在覆核；其餘4縣市尚待建立。來源索引或條文摘錄狀態為 in_review，不等於 verified。現行《都市更新條例》容積獎勵核心條文已校正為第65條，舊第44條不得作為現行容積獎勵授權條文。另新增中央都市更新及危老容積獎勵子法紀錄。

## 稅目參數獨立維護
地價稅、土地增值稅、房地合一所得稅、契稅及房屋稅各自獨立資料檔；中央法規只提供法源，不直接取代稅目參數與公式。已依中央法條初步摘錄部分地價稅、土地增值稅、房地合一、契稅及房屋稅參數；全部仍為 in_review、無有效日期核准且禁止自動套用。地方年度稅率、門檻、稅籍歸戶及個案資格仍須逐縣市核對。現行網站稅務公式尚未改由這些參數驅動，需完成公式對照與回歸測試後才能接管。

## 獎勵引擎安全門

新增 `workbench/modules/reward-engine.mjs`：只接受已驗證法源、有效期間、轄區、個案核准紀錄、經核准獎勵樓地板面積及互斥群組；缺一即阻擋。這是隔離測試模組，尚未接入正式網站土地坪效 UI，不能宣稱容積獎勵計算已完成。

### 地方規定效力風險案例
苗栗縣都市更新建築容積獎勵辦法第3條曾規定特定策略性更新案件得核予2倍基準容積，但內政部115年1月12日函認定該條牴觸《都市更新條例》第65條第5、6項及《地方制度法》第30條，函告無效。資料庫已將其列為不得套用的失效規定；此案例說明地方條文不能只看發布文本，還必須追蹤中央備查/函告無效及法規效力資料。
