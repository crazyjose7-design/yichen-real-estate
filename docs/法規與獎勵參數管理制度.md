# 中央法規、22縣市與獎勵資料管理制度

## 資料拆分
1. `regulations/cities/`：22縣市各自一檔。
2. `regulations/national/`：中央法律與授權子法獨立紀錄。
3. `regulations/rewards/`：容積獎勵/開發獎勵按制度獨立建檔。
4. `regulations/taxes/`：各稅目參數，與法規原文分開。
5. `regulations/schemas/`：資料格式約束。

## 驗證流程
收集官方法源 → 核對現行條文及施行日期 → 確認適用對象與管轄 → 建立參數 → 第二人覆核 → 公式/回歸測試 → 版本發布。任何一步未完成，狀態不得標為 verified。

## 獎勵資料特別規則
容積獎勵不可只存百分比。必須同時存法源、基準容積、計算方式、上限、資格、證明文件、審議/核准狀態、互斥與併計規則、有效期間。中央與地方規則分層；基地個案核准值須另存個案紀錄，不得污染通用法規參數。

## 本階段建置狀態（2026-11-27，v0.1.2）
- 22/22縣市均已定位官方法規入口或具體地方規定來源。
- 19縣市已定位都市更新、容積獎勵或相關基地管制規定；南投、宜蘭、臺東目前僅定位官方法規入口，仍待查得具體地方規定。
- 已建立5項中央授權子法紀錄：都市更新容積獎勵辦法、危老容積獎勵辦法、都市更新條例施行細則、都市更新權利變換實施辦法、危老條例施行細則。全部仍為 in_review。
- 現行《都市更新條例》容積獎勵核心條文已校正為第65條；舊第44條不可作為現行容積獎勵授權條文。
- 苗栗縣都市更新容積獎勵辦法第3條已由內政部函告無效，已記錄為禁止套用；基隆舊核算標準及雲林舊核計原則已標示為廢止/停止適用。

**重要限制：** 22縣市均有來源入口，不代表地方自治法規、完整附表、都市計畫書圖、土地使用分區及基地個案已逐條查證。所有地方法規及參數仍須確認現行版本、生效日、主管機關審查與個案核准。

## 稅目參數獨立維護
地價稅、土地增值稅、房地合一所得稅、契稅及房屋稅各自獨立資料檔。已依中央法條初步摘錄部分稅率/級距，但全部仍為 in_review，禁止自動套用。地方年度稅率、門檻、稅籍歸戶、有效日期及個案資格仍須逐縣市核對。現行網站稅務公式尚未改由這些參數驅動，需完成公式對照與回歸測試後才能接管。

## 獎勵引擎安全門
新增 `workbench/modules/reward-engine.mjs`：只接受已驗證法源、有效期間、轄區、個案核准紀錄、經核准獎勵樓地板面積及互斥群組；缺一即阻擋。這是隔離測試模組，尚未接入正式網站土地坪效 UI，不能宣稱容積獎勵計算已完成。

## 法規效力風險案例
苗栗縣都市更新建築容積獎勵辦法第3條曾規定特定策略性更新案件得核予2倍基準容積，但內政部115年1月12日函認定該條牴觸《都市更新條例》第65條第5、6項及《地方制度法》第30條，函告無效。地方條文不能只看發布文本，還必須追蹤中央備查、函告無效、廢止及法規效力資料。

## 土地坪效官方獎勵安全檢核
正式土地坪效已接入獎勵安全檢核介面。任何獎勵要套用，必須同時具備已覆核法規及參數、明確有效日期、基地轄區、官方法源及條文、覆核人員、主管機關個案核准紀錄、核准增加樓地板面積及互斥/併計群組。檢核未通過時套用按鈕維持停用，官方核准獎勵比例保持0；手動欄位僅為使用者情境假設。
