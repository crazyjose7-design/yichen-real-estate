# 億辰房產網站｜法規參數與修改驗收制度
版本 1.0.0｜2026-11-27

## 核心鐵律
1. 沒有可回復備份，不修改正式來源。
2. 沒有官方法源及適用日期，不填入可供計算的法規數值。
3. 沒有測試案例、預期答案及通過紀錄，不得宣稱驗收完成。
4. 未完成回歸、手機/桌機及列印驗收，不得部署 production。
5. 核定資料、使用者輸入、系統假設及估算值必須分離標示。

## 狀態
- draft：草稿，不得計算。
- pending_official_verification：待官方查證，不得計算。
- verified：必須有官方來源 URL、法規依據、公告日、施行日、查證日期及查證人。
- expired：失效，不得供新案件套用；保留歷史版本。

本次只建立架構、模板與驗證流程。既有 index.html 不修改；空白模板不構成22縣市或12稅目已完成法規查證的證明。

## 驗收閘門
備份與雜湊 → 官方法源查證 → 公式/邊界/例外測試 → 回歸測試 → 桌機/手機/列印驗收 → 預覽部署驗收 → 核准後 production 部署。
