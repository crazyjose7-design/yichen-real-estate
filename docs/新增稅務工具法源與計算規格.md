# 新增稅務工具：租金扣繳與執行業務所得

本文件記錄 2026-11-27 開發分支新增之兩項稅務工具。所有金額均為新臺幣。

## 一、租金扣繳計算機

### 一般欄位
- 本次租金給付總額
- 所得人身分：境內居住者／非境內居住者
- 所得人類型：個人／公司或法人

### 計算依據
- 境內居住者及境內有固定營業場所之營利事業：租金扣繳率10%。
- 非境內居住者及境內無固定營業場所之營利事業：租金扣繳率20%。
- 境內居住個人依第13條、境內有固定營業場所之營利事業依第13-1條，每次應扣繳稅額不超過2,000元者免予扣繳。非居住者不得套用此門檻。
- 進階選項可估算個人租金補充保險費：單次給付達20,000元，以全額計費，費率2.11%，單次計費上限10,000,000元。公司/法人受款人不套用個人租金補充保費。
- 基本版假設租金給付額就是扣繳及補充保費費基。尚未自動處理租約約定由承租人負擔稅費的gross-up、押金設算、代付費用、特殊租賃型態或受款人健保身分例外。

### 主要法源
- 所得稅法第88條、第89條、第92條。
- 各類所得扣繳率標準第2條、第3條、第13條、第13-1條。
- 財政部稅務入口網租賃所得扣繳問答。
- 全民健康保險法第31至33條、全民健康保險扣取及繳納補充保險費辦法第3至5條，以及健保署補充保險費計算公式。

## 二、執行業務所得計算

### 一般欄位
- 本次執行業務報酬給付總額
- 所得人身分：境內居住者/境內有固定營業場所，或非境內居住者/境內無固定營業場所
- 報酬類型：一般執行業務報酬，或稿費、版稅、樂譜、作曲、編劇、漫畫、講演鐘點費等特定所得

### 扣繳計算依據
- 境內居住者及境內有固定營業場所營利事業：10%。
- 非境內居住者及境內無固定營業場所營利事業：20%。
- 境內居住者/境內固定營業場所營利事業，每次應扣繳稅額不超過2,000元免扣；非境內居住者之特定稿費等，每次給付額不超過5,000元免扣。
- 進階選項可估算執行業務收入補充保費：單次給付達20,000元，費率2.11%，單次計費上限1,000萬元；專技自行執業且以職業工會投保等法定例外須由使用者核實勾選。

### 全年所得額估算（進階）
- 所得年度、全年執行業務收入、全年直接必要費用合計、已扣繳稅額（選填）

### 進階欄位
- 業務房租、人員薪資、藥品/材料、設備折舊及修理、旅費、其他直接必要費用。
- 可選擇使用費用明細合計，取代一般欄位費用總額。
- 可選擇費用率模式，但必須自行輸入費用率並勾選已核對所得年度及職業別的財政部官方標準。系統不預設費用率。

### 計算依據
- 所得稅法第14條第1項第2類：執行業務所得為業務或演技收入，減除業務房租或折舊、器材設備折舊及修理、藥品材料成本、雇用人員薪資、旅費及其他直接必要費用後之餘額。
- 執行業務所得查核辦法第3條：原則採收付實現制。
- 同辦法第8條：有帳簿文據者依帳載核實認定；未能提供者依依法核定之費用標準核定。
- 同辦法第14條、第17條：費用須屬直接必要且應有原始憑證。
- 同辦法第15條：混合供業務與非業務使用之費用須按比例計算。
- 同辦法第30條：固定資產折舊應按規定方法、耐用年數及成本限制處理。

### 年度標準限制
- 財政部114年度執行業務者費用標準於115年3月27日發布，僅供114所得年度適用。
- 不得將114年度費用率直接套用115所得年度。115年度各職業費用標準未經核實前，系統不提供自動費用率。

### 計算結果限制
本工具一般欄位計算執行業務報酬扣繳；進階全年所得分析只計算執行業務所得額，不計算個人綜合所得稅最終應納稅額。已扣繳稅額僅列為預扣/可能扣抵資訊，不從執行業務所得額中扣除。所得額為負數時僅顯示估算虧損，不自動抵減其他類所得。
