# 容積獎勵安全引擎與土地坪效整合

## 目前整合方式
- 土地坪效區新增「官方容積獎勵核准檢核（進階）」收合區。
- 使用者選擇基地縣市、試算基準日及獎勵類型後，介面讀取中央獎勵資料並呼叫瀏覽器版安全檢核引擎。
- 引擎逐項檢查法規覆核狀態、自動套用授權、覆核人員、官方法源/條文/主管機關、生效期間、基地轄區、個案主管機關核准紀錄、核准增加樓地板面積及互斥/併計群組。
- 只有引擎回傳verified時，「套用已核准獎勵」才會啟用；套用後將核准增加樓地板面積換算成相對基準容積比例，寫入獨立的官方核准欄位，再觸發土地坪效重新試算。
- 官方核准獎勵欄位與使用者手動輸入的情境獎勵分開，不互相覆蓋；基地面積、單位或法定容積率改變時，先前核准檢查會失效並清除官方獎勵比例。

## 現況
目前9份獎勵資料均未完成逐項法律覆核，沒有已核准的個案紀錄、核准增加樓地板面積或完整互斥群組，因此檢核結果應為blocked，套用按鈕維持disabled，官方核准獎勵比例保持0。既有土地坪效中手動獎勵欄位仍只屬情境假設，不得宣稱為法定可取得容積。

- 土地坪效計算：workbench/modules/land-efficiency.js
- 單元測試：tests/reward-engine.test.mjs、tests/reward-engine-runtime.test.mjs
- 瀏覽器測試：tests/browser-smoke.mjs

## 尚需完成
- 逐一完成中央獎勵子法及22縣市自治法規、附表、計算公式與互斥/併計規則。
- 每一項獎勵需有正式生效日期、適用轄區、法源條文、覆核人員、個案核准編號及核准增加樓地板面積。
- 依個案適用之都市計畫書圖、基準容積、特別上限及過渡條款建立核准總量上限。
- 上述資料經法律覆核後，才可逐項啟用自動套用。
