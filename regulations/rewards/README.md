# 獎勵制度（容積獎勵等）獨立資料

獎勵制度與一般土地/稅務參數分開維護。中央法源、中央子法、地方自治規定、地方都市計畫及個案核准條件必須分層記錄；不得把不同法源的獎勵直接相加。

每一獎勵項目必須記錄：法源及條次、主管機關、適用對象/基地條件、申請程序、計算基礎、上限、是否可併計/互斥、有效期間、官方來源、審查核准文件欄位及覆核紀錄。沒有官方依據的比例/數值一律不填，狀態維持 unverified，不得進入坪效試算。

初始分類：
- 都市更新容積獎勵
- 危險及老舊建築物重建（危老）容積獎勵
- 綠建築相關獎勵
- 智慧建築相關獎勵
- 無障礙環境/通用設計相關獎勵
- 耐震設計/性能相關獎勵
- 大眾運輸導向及地方都市計畫獎勵
- 公益設施、開放空間及其他地方獎勵

以上是查核分類，不代表每一類在所有縣市均存在或可併計。
