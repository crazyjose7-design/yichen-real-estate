# 法規、縣市、稅目與獎勵資料總目錄

- `cities/`：22縣市獨立資料檔。
- `national/`：中央法律與授權子法獨立紀錄。
- `taxes/`：地價稅、土地增值稅、房地合一、契稅、房屋稅參數。
- `rewards/`：都市更新、危老及其他開發獎勵制度。
- `schemas/`：資料結構規格。
- `manifest.json`：整合載入清單。

**資料集狀態：開發中，非正式法規資料庫完成版。**

## 2026-11-27 法源覆核增補（v0.1.2）

- 22/22縣市均已建立官方法規入口或具體地方規定來源紀錄；其中19縣市已定位都市更新、容積獎勵或相關基地管制規定，南投、宜蘭、臺東目前僅定位官方法規入口，尚待在入口內找到具體適用規定。
- 新增中央授權子法：都市更新建築容積獎勵辦法、危老建築容積獎勵辦法、都市更新條例施行細則、都市更新權利變換實施辦法、危老條例施行細則。均為 `in_review`，不得自動套用。
- 校正現行《都市更新條例》容積獎勵核心授權為第65條，並記錄一般上限、特別上限、地方自治法規0.2倍/0.4倍上限、互斥及過渡適用。
- 記錄苗栗縣容積獎勵辦法第3條已遭內政部函告無效；基隆舊核算標準及雲林舊核計原則列為廢止/停止適用。
- 五個稅目已摘錄中央法條初步稅率或級距；全部仍為 `in_review`，地方年度公告、有效日期、個案資格及公式對照尚未完成。
- 土地坪效單獨列印已調整為輸入條件、選填官方查核、成本與試算結果整合一張直式 A4；新增 Playwright 實際輸出 PDF 的頁數及 A4 尺寸驗收，並將測試 PDF 納入 CI artifact。此項仍須以最新 CI 結果確認。
- 新增容積獎勵安全引擎與測試；目前是隔離模組，尚未接入正式土地坪效 UI。網站正式稅務公式也尚未改由參數檔驅動。
- 22縣市的地號套疊、都市計畫書圖、完整地方自治法規及個案核准資料仍待覆核。未驗證資料一律不得自動套用。

## 2026-11-27 新增稅務工具
- 新增租金扣繳：依各類所得扣繳率標準第2、3、13、13-1條區分境內/非境內身分及每次2,000元起扣門檻；進階選項另估個人租金補充保費2.11%、單次2萬元下限與1,000萬元上限。
- 新增執行業務所得：依所得稅法第14條第1項第2類及執行業務所得查核辦法，計算收入扣除直接必要費用；進階費用率必須由使用者依年度及職業別核對後輸入，不預設未核實費用率。
- 兩項工具及中央法源已各自建立 JSON 檔，所有參數維持 in_review，未完成二次覆核前不宣稱正式法規資料庫完成。

- 新增執行業務報酬扣繳：境內10%、非境內20%；境內每次扣繳稅額2,000元以下免扣，非境內特定稿費等每次5,000元以下免扣；進階全年收入減必要費用估算。
- 新增全民健康保險法與補充保險費扣取辦法法源紀錄；補充保費2.11%、單次給付達20,000元，超過1,000萬元部分免扣，並保留投保資格/法定免扣人工確認。
