# 法規、縣市、稅目與獎勵資料總目錄

- `cities/`：22 縣市獨立參數檔。
- `national/`：中央法規獨立紀錄。
- `taxes/`：地價稅、土地增值稅、房地合一、契稅、房屋稅獨立參數檔。
- `rewards/`：都市更新、危老及其他開發獎勵制度檔。
- `schemas/`：資料結構規格。
- `manifest.json`：整合載入清單。

**目前資料集為開發中版本。** 城市檔尚無經覆核的地方參數；部分中央法規及獎勵已定位官方法源，但尚未完成完整子法、地方自治規定、有效日期及計算條件覆核。未驗證資料一律不得自動套用。

## 2026-11-27 法源覆核增補

- 新增《都市更新建築容積獎勵辦法》及《都市危險及老舊建築物建築容積獎勵辦法》獨立中央子法紀錄，摘錄部分條文與互斥、順序及保證金查核點；狀態仍為 `in_review`，不得自動套用。
- 臺北、新北、桃園、臺中、臺南、高雄、基隆、嘉義市、苗栗、雲林、花蓮、澎湖已建立地方官方法規來源索引（12/22）。這代表已定位官方入口或法規，不代表逐條、附表、基地圖資及個案核准覆核完成。
- 新增容積獎勵安全計算模組與回歸測試：未驗證、無官方條文、無有效日期、無地方轄區或無個案核准紀錄，一律阻擋；互斥群組不得逕行加總。
- 目前僅4/22縣市具地方官方來源索引；其餘18縣市尚待建立。任何法規與獎勵仍保持關閉自動套用。
