# 億辰房產網站 V2｜獨立驗證與完整驗收工程

本目錄建立與網站執行程式分離的驗證層。任何一層通過，不代表下一層通過。

## 五層驗收閘門

| 層級 | 驗收範圍 | 通過條件 | 不得替代 |
|---|---|---|---|
| 1. 官方資料與法規來源 | 官方法規、附件、版本、生效日、縣市 | 每筆來源可追溯；官方全文及附件已核對；版本狀態明確 | 不能以資料檔存在視為法規有效 |
| 2. 獨立公式驗證引擎 | 獨立公式、預期值、邊界值、異常值、交叉核算 | 預期值由獨立算法或權威依據建立；涵蓋邊界/異常/性質測試；與第二種方法交叉核對 | 不能引用網站自身函式產生 expected |
| 3. 法規適用引擎 | 22縣市、中央子法、獎勵條件、互斥與併計 | 每項規則有條次/附件/日期/地域/適用條件；互斥與併計有明確測試；未核實規則不得啟用 | 不能以公式算對視為法規套用正確 |
| 4. 網站實際功能驗收 | 瀏覽器輸入、操作、計算、表格、PDF、響應式 | Playwright 真實操作頁面；核對輸入、結果、中間表格、錯誤提示及列印輸出 | 不能以單元測試或網站可開啟代替 |
| 5. 全系統整合驗收 | 全測試、部署包、部署前檢查 | 1–4層證據齊全；全量回歸通過；部署包可重現且完整；部署前檢查通過 | 不得以 CI 綠燈直接視為正式上線 |

## 子目錄

- `python/`：獨立 Decimal 計算核心與不依賴網站程式的測試。
- `schemas/`：驗收證據資料格式。
- `browser/`：Playwright 瀏覽器測試（下一階段依網站實際 DOM/欄位建立測試）。
- `reports/`：各層驗收報告與未通過項目。

## 執行 Python 獨立測試

Python 3.11+，只使用標準函式庫，無需付費或安裝第三方套件：

```bash
python -m unittest discover -s verification/python -p "test_*.py" -v
```

## Playwright 安裝（開發/CI 環境）

Playwright 開源且免費。於可執行 Node.js 的電腦或 CI 執行：

```bash
npm install --save-dev @playwright/test
npx playwright install --with-deps chromium
```

Android 手機不需要安裝；瀏覽器測試由 GitHub Actions/Linux runner 執行。正式接入前，必須先盤點實際頁面路由、表單欄位、計算按鈕、結果表格與列印入口，不可猜測 selector。

## 狀態原則

- `NOT_STARTED`：尚未建立測試證據。
- `IN_PROGRESS`：已有部分案例，尚未達到完整矩陣。
- `BLOCKED_SOURCE`：缺官方法源、附件或可核實版本。
- `PASS`：符合該層全部驗收條件，且有可追溯報告。
- `FAIL`：測試或證據不符合條件。

本架構建立本身不代表五層驗收通過。所有尚未完成的稅務、土地坪效、房貸與22縣市法規矩陣，必須逐項補齊並產生證據。
