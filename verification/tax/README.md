# 稅務獨立驗證工作包

網站版本註記「14項工具」，但目前抽出的 `workbench/modules/tax-engine.js` 只有12個計算器定義：土地增值稅、房地合一稅、房屋舊制財產交易所得、營業稅、契稅、印花稅、房屋稅、地價稅、租賃所得稅、遺產稅、贈與稅、營利事業所得稅。HTML中找到租金扣繳及執行業務所得的法規連結與14項版本說明，但目前模組未找到這兩個計算器定義。差異列為阻擋項，不得算已完成。

每項工具必須有獨立公式規格、欄位規格、年度/法源、expected fixtures、正常/邊界/異常/交叉案例。expected不可由網站函式反算。地方稅率、免稅額、扣除額、費用率及公告門檻須綁年度、縣市及有效日期。資格未確認時必須阻止套用優惠。來源未確認標記 `BLOCKED_SOURCE`。

現有單一基準值只屬候選值，尚需核對法規版本、扣除順序、四捨五入及適用條件。
