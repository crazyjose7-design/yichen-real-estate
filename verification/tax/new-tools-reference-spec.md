# 新增兩項稅務工具｜指定介面與法規基準

## 一、租金扣繳計算機

指定介面來源：Simpany「租金扣繳計算機」https://simpany.co/rent-withholding-calc

### 不得自行增加的一般輸入欄位
1. 房東：個人／公司
2. 每期租金
3. 租金已含稅／租金未含稅

### 進階設定（收合）
- 多位房東
- 各房東持分
- 各房東本國人／外國人

### 結果欄位
- 每位房東每期租金（含稅）
- 扣繳比例及扣繳金額
- 二代健保2.11%及保費金額
- 租扣二代合計
- 實際支付租金（未稅）

### 法源核對阻擋點
財政部稅務入口網對租賃所得說明：境內居住個人及境內有固定營業場所營利事業原則10%；非境內居住個人及境內無固定營業場所營利事業原則20%。Simpany教學文章則描述公司房東可不處理扣繳。兩者適用條件不能混為一談，必須先釐清「公司」的稅籍/固定營業場所狀態及本計算機是否採簡化假設，不得只憑房東個人/公司兩選項套用錯誤稅率。

健保署補充保險費公式：租金收入單次給付達20,000元為起扣門檻，費率2.11%，費基達下限時按全額計算；上限1,000萬元。若承租人另代房東負擔扣繳稅款或補充保費，可能須回推含稅租金費基，不可直接用實收租金乘2.11%。

## 二、執行業務所得扣繳計算機

指定介面來源：https://simpany.co/professional-income-calc

### 一般輸入欄位（僅四項）
1. 身分
2. 申報類別
3. 健保身分
4. 金額

金額區需保留「實領金額」模式（依來源頁功能）。

### 結果區塊
**公司應預扣及發放的金額**
- 所得金額
- 代扣所得稅
- 代扣二代健保
- 實際支付金額

**補充：對所得人個人所得的影響**
- 所得金額
- 費用率
- 計入所得淨額

### 常見執行業務類別
至少依來源頁呈現9A執行業務所得、9B稿費/演講/出席費等類別及其說明、所得計算與公司注意事項。費用率不得自行編造；必須依當年度財政部執行業務者費用標準及實際申報類別帶入。

## 三、已找到的法規依據（仍須轉成版本化資料及測試）

- 財政部稅務入口網：執行業務所得扣繳；境內居住個人10%、非居住者20%，9B稿費等另有免扣繳門檻。
- 財政部稅務入口網：租賃所得扣繳；境內居住個人/境內有固定營業場所營利事業10%，非居住者/境內無固定營業場所營利事業20%。
- 健保署：補充保險費公式；租金收入、執行業務收入單次給付達20,000元起扣，費率2.11%，上限1,000萬元。
- 財政部各年度執行業務者費用標準：需按所得年度與細分類別取值，不可固定套用單一比例。

## 四、驗收要求

- 表格結構與欄位不得偏離指定來源；不可把專業法規選項擅自放在一般輸入區。
- 一般區只保留上述欄位；特殊條件收在進階設定。
- 每一種身分、申報類別、健保身分均有邊界與異常案例。
- 19,999、20,000、20,001元門檻測試；租金含稅/未含稅回推測試；9B 2,000元扣繳門檻及全年費用標準測試。
- 公司房東、外國房東/非居住者及多房東持分需以官方規則逐項確認。
- expected 需由獨立Decimal oracle及官方依據建立，不可用前端函式自我驗證。
