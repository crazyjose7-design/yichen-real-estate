# 土地坪效四頁列印驗收

狀態：IN_PROGRESS

## 指定四頁與順序
1. 基地法規：基地條件、法定使用/容積等資訊。
2. 官方查核：選填區塊；只有使用者確實填寫/選取查核資料時才輸出。未填不得產生空白頁。
3. 土地成本：土地取得成本、單位成本、分攤及相關輸入。
4. 試算結果：樓地板、可售面積、銷售收入、成本及結果說明。

## 必須符合
- 各區塊各自一頁A4，不可混印、合頁或錯序。
- 官方查核頁條件式輸出，不填即略過，不保留空白頁。
- 每頁只顯示該頁所屬內容，頁首/頁尾一致。
- 長文字、長地址、多筆基地資料不得截斷。
- 列印資料必須與當次畫面輸入及結果一致。

## 測試矩陣
- 官方查核空白/有填兩種。
- 最小/最大基地面積、坪/平方公尺。
- 多筆法規查核、長說明、無獎勵/多項獎勵情境。
- 四頁頁數與順序自動檢查，並逐頁人工視覺檢查。

## 證據
保存兩種條件的PDF、頁面文字抽取、每頁截圖、實際頁數及資料一致性結果。
