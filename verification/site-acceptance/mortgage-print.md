# 房貸專區列印驗收

狀態：IN_PROGRESS

## 必須符合
1. 列印按鈕位於房貸試算區塊下方。
2. 只列印房貸區塊，不可混入稅務、土地坪效或其他網站內容。
3. A4直式。
4. 包含全部輸入資料。
5. 包含原網站定義的六項試算結果，不得漏項或擅自改成其他摘要。
6. 包含完整試算說明。
7. 包含前12期攤還明細（期數、期付金額、本金、利息、剩餘本金等網站實際欄位）。
8. 未完成試算前，列印功能不得輸出舊資料或空白報表。

## 測試矩陣
- 本息平均、本金平均。
- 有/無寬限期。
- 0利率、一般利率、利率變動。
- 20/30/40年及不同貸款金額。
- 前12期明細逐期與網站計算結果比對。
- PDF頁數、A4直式、欄位不截斷、表格不跨頁錯位。

## 證據
每個情境保存輸入、六項結果、前12期逐期資料、PDF頁面與獨立計算核對結果。
