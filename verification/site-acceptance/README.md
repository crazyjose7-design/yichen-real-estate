# 網站原始功能驗收總表

本資料夾將原始網站功能與六大法規/計算工作分開驗收，最後再做跨功能整合。不得以頁面載入、PDF 可產生或單一 smoke test 取代完整驗收。

| 工作包 | 獨立驗收檔 | 完成條件 |
|---|---|---|
| 稅務單項列印 | tax-print.md | 僅列印目前選取且已試算的稅務工具；A4直式；輸入、結果、說明完整；不混入其他工具 |
| 房貸列印 | mortgage-print.md | 僅列印房貸；輸入、六項結果、說明、前12期明細齊全；A4直式 |
| 土地坪效列印 | land-print.md | 四個指定區塊各自獨立一頁；官方查核未填則不輸出該頁；不混印 |
| 整份網站列印 | full-site-print.md | 指定網站區塊依原規格分頁；只有已完成試算的工具才加入 |
| RWD視覺驗收 | responsive-visual.md | 桌面、平板、手機多尺寸實際瀏覽器檢查 |
| 聯絡表單送達 | contact-delivery.md | 以實際收件端收到的測試信/紀錄證明成功 |
| Cloudflare Pages | cloudflare-deployment.md | 正式專案設定、部署完成、網址可用、部署版本與驗收 commit 一致 |

## 狀態定義
- NOT_STARTED：尚未執行
- IN_PROGRESS：正在執行
- BLOCKED：有明確阻礙
- FAIL：測試已執行但未通過
- PASS：有可追溯測試證據且符合全部條件

不得以文件建立、語法檢查、CI部分成功或測試工具能啟動標示PASS。

## 跨工作整合閘門
全部七個工作包先各自PASS，六大計算/法規工作也分層通過後，才執行整站跨功能回歸、列印組合測試、聯絡表單實際收件、正式部署前檢查。未經使用者明確要求，不合併main、不切換正式流量。
