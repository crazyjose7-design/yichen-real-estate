## 驗收要求
每個模組至少建立一般、邊界、特殊資格、不適用及未核實資料停止計算案例。每個案例記錄輸入、預期值、容許誤差、法源版本及測試日期。

## 靜態盤點已發現的高風險項目
- 土地增值稅：CPI時間序列、長期持有級距、自用住宅及抵繳規則。
- 房地合一稅：新舊制過渡、取得方式、居住者、股份交易、自住及重購退稅。
- 房屋舊制：年度公告設算標準及縣市/鄉鎮地區門檻。
- 營業稅：一般加值型、小規模查定、特種稅額、免稅及零稅率。
- 契稅：核定契價、交換價差、先典後賣抵繳、信託及免稅。
- 印花稅：憑證種類、份數、免稅、正副本及每件尾數。
- 房屋稅：22縣市差別稅率、全國歸戶、現值門檻及特殊減免。
- 地價稅：各縣市累進起點地價、自用住宅及特別稅率。
- 租賃所得：一般出租、社宅、公益出租、包租代管及年度費用率/利率。
- 遺產/贈與稅：發生日版本、免稅額、扣除額、累進級距及財產價值認定。
- 營利事業所得稅：課稅年度、起徵額、組織型態、虧損扣除及基本稅額。

以上為風險盤點，不是公式正確性判定。尚未完成完整法條核對及測試前，所有參數維持 pending_official_verification。
